# Password Detection and Generation

## About the Project

Password Detection and Generation is a Python-based web application developed using Flask. It provides a web interface for checking password strength and generating passwords.

The project aims to help users understand password security and create stronger passwords.

## Features

- **Password Strength Detection:** Check the strength of a password.
- **Password Generation:** Generate passwords for improved security.
- **Web Interface:** Interact with the application through a browser.
- **Python and Flask Backend:** Process application requests on the server.
- **User-Friendly Design:** Simple interface for easy use.

## Technologies Used

- Python
- Flask
- HTML
- CSS

- Python 3.13 or a compatible Python version
- pip (Python package installer)
- A web browser
- Visual Studio Code (recommended)

## Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/drajj-0011/Password-Detection-and-Generation.git
```

### 2. Open the Project Folder

```bash
cd Password-Detection-and-Generation
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open the Website

Open your browser and visit:

```text
http://127.0.0.1:5000
```

Keep the terminal running while using the application.
